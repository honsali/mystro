# Retired REST Roadmap

This historical roadmap is retired.

Mystro no longer has a Spring Boot REST application, REST endpoints, web adapter package, or server-served resources. The current runtime contract is the command-line main documented in `docs/SPECIFICATION.md`:

```bash
java -jar target/mystro-<version>.jar <native-list-alias>
```

Keep this file only as a reminder that the old web/API direction was intentionally removed.
